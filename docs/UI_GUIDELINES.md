# UIガイドライン

## 方針

```
Professional / Minimal / Dense / Fast / Dark
```

パネル型の編集ワークスペースという業界標準のレイアウトを踏襲するが、
配色・アイコン・命名・UIアセットは独自に作る。既存製品のアセットや
配色そのものは使わない。

## カラー

`tailwind.config.js` にトークンとして定義。

| トークン | 値 | 用途 |
| --- | --- | --- |
| `bg` | `#121417` | アプリ背景 |
| `panel` | `#1A1D21` | パネル面 |
| `panel-alt` | `#15181C` | ヘッダー・ツールバー |
| `border` | `#2A2F36` | 境界線 |
| `text` | `#F4F4F5` | 本文 |
| `text-secondary` | `#A1A1AA` | ラベル |
| `text-muted` | `#71717A` | 補助情報 |
| `accent` | `#4CC2A5` | 選択・再生ヘッド・主要アクション |
| `video` / `audio` / `adjustment` | `#3E6E9E` / `#4E7A56` / `#8A6BB1` | クリップ種別 |

アクセントは独自のブランドカラーとして設定している。

## レイアウト

```
TopBar（メニュー / プロジェクト名 / Undo / Redo / Export）
┌─────────────┬──────────────────┬─────────────┐
│ Media       │ Preview Monitor  │ Inspector   │
├─────────────┴──────────────────┼─────────────┤
│ Timeline                       │ AI Assistant│
└────────────────────────────────┴─────────────┘
StatusBar（タイムコード / 解像度 / ジョブ進捗）
```

## 密度

- 本文13px、ラベル10px（`text-2xs`）。
- パネルヘッダーは32px固定、ツールバーは32px、ステータスバーは24px。
- タイムコードとフレーム値は等幅フォント。

## 操作の原則

- ドラッグ中はローカルにプレビューし、離した時点で1つのCommandを発行する。
  ドラッグ1回 = Undo 1回。
- 破壊的操作は必ずUndoできる。確認ダイアログでUndoを代替しない。
- 実装していない機能は、それらしく振る舞わせず、できないと明示する。

## ショートカット

| キー | 動作 |
| --- | --- |
| `Space` | 再生 / 一時停止 |
| `V` / `C` | 選択ツール / レーザーツール |
| `S` | スナップ切り替え |
| `Delete` / `Shift+Delete` | 削除 / リップル削除 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / Redo |
| `Ctrl+S` | 保存 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` / `Ctrl+D` | コピー / カット / ペースト / 複製 |
| `←` / `→` | 1フレーム移動（`Shift`で1秒） |
| `+` / `-` | タイムラインズーム |
| `Home` | 先頭へ |
