# 使い方

## 0. Web版（インストール不要）

ブラウザだけで動きます。FFmpegもインストールも不要です。

リポジトリの **Settings → Pages → Source** を「GitHub Actions」にして
mainブランチへpushすると、次のURLで公開されます。

```
https://taketouhu.github.io/VTa-Videomaker/
```

### 手元で動かす手順（Windows）

**1. Node.js を入れる**

[nodejs.org](https://nodejs.org/) から **LTS版** をダウンロードし、
インストーラを実行します。設定はすべて既定のままで構いません。
インストール後、PCを一度再起動すると確実です。

**2. コードをダウンロードして展開する**

<https://github.com/TakeTouhu/VTa-Videomaker/archive/refs/heads/claude/ai-video-editor-design-dy0skr.zip>

ZIPを右クリック →「すべて展開」で展開します。

> **注意**: Windowsの「すべて展開」は、ZIPと同じ名前のフォルダを作ってから
> 中身を出します。ZIPの中にも同名のフォルダが入っているため、
> **フォルダが二重になります**。
>
> ```
> VTa-Videomaker-claude-ai-video-editor-design-dy0skr\   ← Windowsが作った箱
>     VTa-Videomaker-claude-ai-video-editor-design-dy0skr\   ← 本体
>         start-windows.bat
>         package.json
> ```
>
> 作業するのは **`package.json` があるほうのフォルダ** です。

**3. `start-windows.bat` をダブルクリックする**

本体フォルダの中にある **`start-windows.bat`** をダブルクリックします。

必要なものの確認、初回セットアップ、起動、ブラウザで開くところまで
自動で行います。初回は数分かかります。

終了するときは、開いた黒い画面で `Ctrl + C` を押してください。

（Mac / Linux の場合は `start-mac-linux.sh` を使ってください）

#### コマンドで実行したい場合

`package.json` があるフォルダでターミナルを開き、次を実行します。
フォルダのアドレスバーに `powershell` と入力して Enter を押すと、
その場所でPowerShellが開きます。

```powershell
npm install
npm run dev
```

`Local: http://localhost:1420/` と表示されたら、Chrome か Edge で
<http://localhost:1420/> を開きます。
2回目以降は `npm run dev` だけで構いません。

#### うまくいかないとき

| 表示されたもの | 原因と対処 |
| --- | --- |
| `Missing script: "dev"` | フォルダが違います。二重になったフォルダの**内側**（`package.json` があるほう）に移動してください。`dir` と入力すると今いる場所の中身が見えます |
| `npm : 用語 ... 認識されません` | Node.jsが未インストールか、インストール後に再起動していません |
| `Port 1420 is in use` | 既に起動しています。ブラウザで開くだけでOKです |
| 真っ白な画面 | Chrome か Edge で開いてください（Firefoxは書き出し非対応） |

## 1. デスクトップ版に必要なもの

**でき上がった exe を使うだけなら、必要なのは FFmpeg だけです**
（FFmpeg同梱ビルドを使う場合はそれも不要）。Windows 11なら
WebView2は標準で入っています。

| ソフト | バージョン | 用途 |
| --- | --- | --- |
| [FFmpeg](https://www.gyan.dev/ffmpeg/builds/) | 6以上 | 動画処理（`ffmpeg`と`ffprobe`の両方） |

自分でビルドする、またはソースから起動する場合は加えて次が必要です。

| ソフト | バージョン | 用途 |
| --- | --- | --- |
| [Node.js](https://nodejs.org/) | 18以上 | UIのビルド |
| [Rust](https://rustup.rs/) | 1.77以上 | 本体のビルド |
| Microsoft C++ Build Tools | — | Visual Studio Installerの「C++によるデスクトップ開発」 |

### FFmpegの置き場所

次のいずれかにしてください。上から順に探します。

1. アプリに同梱されている（`npm run fetch-ffmpeg` を実行してビルドした場合）
2. アプリのインストール先にある `bin` フォルダ
3. 環境変数 `PATH` の通ったフォルダ

確認方法:

```
ffmpeg -version
ffprobe -version
```

どちらもバージョンが表示されればOKです。

## 2. exe を入手する

### 方法A: GitHub Actions でビルドする（推奨・環境構築不要）

1. リポジトリの **Actions** タブを開く
2. 左の **Build Windows** を選ぶ
3. **Run workflow** → ブランチに `claude/ai-video-editor-design-dy0skr` を選んで実行
   - 「FFmpegを同梱する」にチェックを入れると、FFmpeg入りのビルドになります
4. 10〜20分ほどで完了。実行結果の **Artifacts** から
   `ai-video-editor-windows` をダウンロード

中身は3種類です。

| ファイル | 用途 |
| --- | --- |
| `*-setup.exe` | インストーラ（推奨）。スタートメニューに登録されます |
| `*.msi` | MSI形式のインストーラ |
| `ai-video-editor.exe` | 実行ファイル単体 |

### 方法B: 自分の Windows PC でビルドする

この方法には後述の開発環境が必要です。

```bash
npm install
npm run fetch-ffmpeg   # FFmpegを同梱したい場合のみ
npm run build:exe
```

でき上がるのは次の場所です。

```
target
eleaseundle
sis\AI Video Editor_0.1.0_x64-setup.exe
target
eleaseundle\msi\AI Video Editor_0.1.0_x64_ja-JP.msi
target
eleasei-video-editor.exe
```

> **FFmpeg同梱について**: 一般的なFFmpegの配布ビルドはGPLです。同梱して
> 第三者に配布する場合はGPLの条件を満たす必要があります。自分で使うだけなら
> 気にする必要はありません。同梱しない場合は、利用者がFFmpegを別途
> 導入することになります。

## 3. 開発環境で起動する

```bash
git clone https://github.com/TakeTouhu/VTa-Videomaker.git
cd VTa-Videomaker
git checkout claude/ai-video-editor-design-dy0skr

npm install
npm run tauri dev
```

初回は Rust のビルドに数分〜十数分かかります。2回目以降は速くなります。

### UIだけ見たい場合

```bash
npm run dev
```

ブラウザで `http://localhost:1420` が開きます。Rust も FFmpeg も不要ですが、
**サムネイル生成・解析・書き出しはできません**（その場合はエラーで
「デスクトップ版が必要です」と表示されます）。画面の確認用です。

## 4. 基本の流れ

```
素材を左のパネルへドラッグ＆ドロップ
        ↓
素材をタイムラインへドラッグ
        ↓
AIアシスタントに指示、または手動で編集
        ↓
Export で MP4 として書き出し
```

### 素材の取り込み

左上の Project / Media パネルに動画ファイルをドラッグ＆ドロップします。
MP4 / MOV / WAV / PNG などに対応しています。取り込むと自動で
サムネイルとプロキシ（編集用の軽い動画）が作られます。

素材にマウスを乗せると短くプレビュー再生されます。

### タイムラインへ配置

素材を下のタイムラインの V1 などのトラックへドラッグします。
配置したら次の操作ができます。

| やりたいこと | 操作 |
| --- | --- |
| 移動 | クリップをドラッグ |
| 長さを変える | クリップの左右端をドラッグ |
| 分割 | `C` でレーザーツールにして切りたい場所をクリック、または `Split` |
| 削除 | 選択して `Delete` |
| 隙間も詰めて削除 | 選択して `Shift + Delete` |
| 元に戻す | `Ctrl + Z` |

### 書き出し

右上の `Export` を押し、出力先とコーデック・解像度を指定して「書き出し」。
進捗が表示され、途中でキャンセルもできます。

GPU欄で「自動検出」を選ぶと、対応するGPUがあれば高速に書き出します。
GPUが無い環境では自動的にソフトウェア処理に切り替わります。

## 5. AI機能を使う

### まず設定する

上部の `設定` を開きます。2つのモードがあります。

**ローカルモード（APIキー不要）**

そのままで次の指示に対応します。

- 「無音部分を全部削除して」
- 「言い直しを削除して」
- 「3分以内にまとめて」

「言い直し」と「まとめる」は文字起こしが必要なので、
設定の「音声認識（ローカル）」に
[whisper.cpp](https://github.com/ggerganov/whisper.cpp) の実行ファイルと
モデルのパスを入れてください。

**APIモード（自由な指示ができる）**

Provider を「OpenAI互換API」にして、APIキーとモデル名を入れます。
すると自由な日本語で指示できます。

- 「最初の30秒をもっとインパクトのある構成にして」
- 「テンポを速くして」
- 「失敗している部分を削除して」

> APIキーはプロジェクトファイルには保存されません。この端末の設定ファイル
> にだけ保存され、画面上ではマスク表示されます。

### 使い方

右下の AI Assistant に指示を入力して送信します。

```
ユーザー：無音部分を全部削除して

AI：12箇所の無音（合計 34.2 秒）を削除します
    [Apply] [Reject] [Edit Plan]
```

**AIはいきなりタイムラインを書き換えません。** 必ず編集案として提示され、
`Edit Plan` で1件ずつ中身を確認できます。`Apply` を押して初めて反映されます。

適用後も普通のクリップなので、手で微調整できます。
気に入らなければ `Ctrl + Z` 一回でAI編集全体が元に戻ります。

### その他のAI指示

| 指示 | 動作 |
| --- | --- |
| 一番良いテイクだけ残して | 同じ内容の撮り直しを検出し、よどみの少ないものを残す |
| ハイライトを60秒でまとめて | 重要な部分だけを時系列順に残す |
| 色を自動補正して | 明るさ・コントラスト・色被りを実測して補正 |
| 音量を揃えて | 放送基準のラウドネスに合わせる |
| 字幕を作って | 文字起こしから字幕を生成（字幕タブで編集可） |

## 6. 色と効果

クリップを選んで右の Inspector を使います。

- **EFFECT タブ** … 位置・拡大・回転・不透明度、エフェクト、マスク
- **COLOR タブ** … 明るさ〜彩度の9項目、`Curves` でトーンカーブ
- **AUDIO タブ** … 音量・パン・フェード

### 一部分だけ色を変える

2通りあります。

1. **調整レイヤー**：`Adjustment` ボタンで上のトラックに追加し、色を変える。
   下にあるクリップすべてに適用されます。
2. **マスク**：Inspector の Masks で円や矩形を追加すると、その範囲だけに
   エフェクトと色調整がかかります。`トラッキング` を押すと対象物を
   自動で追いかけます（例：人物の顔だけ明るくする）。

### アニメーション

スライダーの横にある ◆ ボタンを押すと、その時点の値がキーフレームとして
記録されます。再生ヘッドを動かして値を変えると、その間が自動で補間されます。

## 7. ショートカット

| キー | 動作 |
| --- | --- |
| `Space` | 再生 / 一時停止 |
| `V` / `C` | 選択ツール / レーザーツール |
| `S` | スナップ切り替え |
| `Delete` / `Shift + Delete` | 削除 / 隙間も詰めて削除 |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 元に戻す / やり直す |
| `Ctrl + S` | 保存 |
| `Ctrl + C` / `V` / `X` / `D` | コピー / 貼り付け / 切り取り / 複製 |
| `←` `→` | 1フレーム移動（`Shift`で1秒） |
| `+` / `-` | タイムラインの拡大 / 縮小 |
| `Home` | 先頭へ |

## 8. 保存について

30秒ごとに自動保存されます（変更があったときだけ）。保存先は

```
ドキュメント/AI Video Editor/<プロジェクト名>/project.json
```

`autosave/` フォルダに世代バックアップも残ります。

**元の動画ファイルは一切変更されません。** 編集内容はプロジェクトファイルに
記録されるだけなので、素材を壊す心配はありません。

## 9. うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| サムネイルが出ない / 書き出しが失敗する | `ffmpeg -version` が通るか確認 |
| 「デスクトップ版が必要です」と出る | `npm run dev` ではなく `npm run tauri dev` で起動する |
| 文字起こしができない | 設定で音声認識エンジンかAPIプロバイダを指定する |
| ビルドが通らない（Windows） | C++ Build Tools が入っているか確認 |
| 4Kで動作が重い | プロキシ生成の完了を待つ（ステータスバーに進捗が出ます） |

エラーは画面右下に表示されます。「詳細」を押すと技術的な内容が見られるので、
問題を報告するときはそれを添えてください。
